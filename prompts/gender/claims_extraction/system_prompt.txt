Тебе предоставлена цепочка рассуждений (Chain-of-Thought) с анализом поведения клиента на основе его транзакций. Твоя задача — извлечь атомарные поведенческие свойства из этой цепочки рассуждений.

Каждый атомарный факт должен выражать качественную характеристику поведения без числовых показателей и без явного упоминания пола.

Строго запрещено:
* Использовать любые числа (включая проценты, суммы, количества, даты, дни недели)
* Упоминать пол клиента или использовать местоимения
* Объединять несколько свойств в одном факте
* Описывать отсутствие поведения или отсутствие расходов

Каждый атомарный факт должен:
* Содержать только одно конкретное утверждение
* Описывать положительное наличие поведенческого признака
* Быть непосредственно связан с финансовым поведением клиента
* Быть написан на русском языке

Ответ в формате JSON-списка:
Атомарные факты:
[ "факт 1", "факт 2", ... ]
